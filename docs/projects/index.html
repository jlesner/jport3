ChartSight: When the Vulnerability Is in the Diagram

ChartSight asks what happens when the harm in a multi-agent AI harness is drawn in an ASCII diagram instead of written in prose. On 80 harnesses that encode the same harms both ways, every analyzer that discriminates did worse on diagrams, and the cheapest setup, one LLM call costing 16 cents in all, scored best.

Slides

Final project for CMPSC 292C, Formal Methods for Agentic Programming (UC Santa Barbara, Spring 2026), taught by Prof. Yu Feng. Presented in class on June 4, 2026.

HAPO: Hyper-reflection for Automatic Prompt Optimization

DBDoctor: LLM-Aided SMT Refutation of SQL Query Equivalence

DBDoctor uses LLMs to propose counterexamples and rewrite queries into SMT-friendly forms, dramatically reducing the rate of “unsupported” query pairs from 100% to 1% and successfully refuting 47% of previously unverifiable cases.

Preprint

Manuscript in progress with Dr. Xifeng Yan.

SymbolSight: Robust Symbols for Retinal Implants

A research project optimizing visual symbol sets for patients with retinal implants. By analyzing confusion matrices over simulated letter recognition using the pulse2percept framework, SymbolSight derives symbol sets that remain distinguishable even under the severe distortions introduced by low-resolution prosthetic vision.

PreprintVideoEMBC 2026 SlidesEMBC 2026 Talk

Presented at IEEE EMBC 2026 in Toronto, with Dr. Michael Beyeler.

NutriGNN: Food Nutrient Prediction with GNNs

A graph neural network approach to predicting missing nutrient values in food composition databases. By building a knowledge graph enriched with LLM-derived semantic relations between foods, NutriGNN improves representation learning and prediction quality, especially for low-resource food items with sparse nutritional data.

Report

Developed for a graduate course on Graphs and GNNs with Dr. Ambuj K. Singh.

SnipDue: Never Miss Another Deadline

A deadline import tool with near universal support for all the ways to represent a schedule. Our tool uses Claude 3.5 Sonnet and works with Google Calendar, Apple Calendar, Outlook, and any iCal-compatible app. For students juggling jobs and coursework, not missing a deadline isn’t a luxury, and SnipDue turns a snapshot of a course schedule into calendar events they can edit.

State Machine Visualizer (SMV)

SMV turns the C code that mechatronics students write for their robots into state diagrams, so they can see and debug their state machines. Regular expressions broke on real student code, so I rebuilt it on abstract syntax trees (pycparser, with XPath and XSLT rules) and kept improving it over two academic years, after the funding ended. The project was advised by Dr. Gabriel Elkaim and began during my CAHSI/NSF-sponsored undergraduate research internship. Dr. Elkaim provided guidance on requirements, while I focused on development and testing.
